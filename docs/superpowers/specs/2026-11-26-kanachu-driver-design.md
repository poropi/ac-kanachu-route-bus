## 1. 目的

今の運転手は、AC に最初から入っているレーシングスーツ姿の運転手（Kunos の `content/driver/driver.kn5`）を、別の MOD（tky_bus_jetset）から借りた 3 ファイル（`data/driver3d.ini`、`driver_base_pos.knh`、`animations/steer.ksanim`）で座らせている。借り物は公開できず、これが無いと CSP が落ちるので外すこともできない。

そこで、**神奈中の運転士の姿をしたオリジナルの運転手**を作り、3 ファイルも自作して借り物を無くす。MIT で公開できる状態にするのが目的。

| 部位 | 内容 |

| 上着 | 濃紺の背広型。襟・袖口・ポケットのふたに青い縁取り、胸に「Kanachu」の刺繍と名札、銀のボタン 3 つ |

決めたこと:

- **姿勢は運転席に座ってハンドルを握る。** 腕はハンドルを回す動きに合わせる。
- 「Kanachu」の文字はバスの塗装と同じく描き直した字で入れる（README で非公式と断っている範囲）。

## 3. 目標・目標外・失敗の条件

- **目標**
  - 運転席の視点で、白い手袋の手がハンドルを握り、ハンドルを回すと手が付いていく。
  - 車外から窓越しに、元絵の運転士だと分かる（制帽・サイドポニーテール・紺の制服・青い縁取り）。
  - 借り物のファイルが 1 つも無く、`tools/check_public.py` が通る。
- **目標外**: 表情の切り替え、口パク、変速の手の動き（AT なので不要）、髪や服の揺れ、乗客。
- **失敗とみなす**
  - 手がハンドルから浮く、またはハンドルや体にめり込む。
  - 顔がアニメ調に見えず崩れている（目・口の位置がずれる、肌が汚く見える）。
  - Kunos のファイル（`driver.kn5` など）や借り物を配布物に入れる。
  - ゲームが落ちる、運転手が表示されない。

## 4. 制約（調べて分かったこと）

- **骨の名前は AC 標準の運転手と同じにする。** `DRIVER:DRIVER` → `DRIVER:RIG_Center` → `RIG_Hips` → `RIG_Cest` → `RIG_Nek` → `RIG_Head`、左右の `RIG_Clave_*`・`RIG_Arm_*`・`RIG_ForeArm_*`・`RIG_ForeArm_END_*`・`RIG_HAND_*`・指 15 本ずつ（`HAND_L_Thumb1-3`、`HAND_Index1-3`／右は `HAND_R_Thumb1-3`、`HAND_Index4-6` など）、`RIG_Shoulder_*`、脚 `RIG_Leg_*`・`RIG_Shin_*`・`RIG_Hill_*`・`RIG_Foot_*`。全階層は `refs/kunos_driver/driver.kn5`（ゲーム PC から取った Kunos の標準の運転手。git 管理外、配布しない）で確かめられる。
- **骨で動くメッシュ（kn5 の種類 3）は 1 頂点 76 バイト（重み 4・骨番号 4）。** 末尾は外接球を持たない（`tools/kn5io.py` で読み書き済み、標準の運転手がバイト一致で読み戻せる）。標準の運転手は服 2,488 頂点（骨 21 本）、手袋 2,330 頂点（骨 36 本）、顔などは頭の骨に付いた固定のメッシュ。
- **運転手の体は `content/driver/<名前>.kn5` に置く**（CSP の `[DRIVER3D_MODEL]` も同じ場所しか指せない）。配布物は `content/cars/kanachu_route_bus/` と `content/driver/kanachu_driver.kn5` の 2 つを、`content/` の形のまま 1 つの zip にする。
- **`driver_base_pos.knh`**: 骨の名前・4×4 行列・子の数を木の形に並べただけの形式（借り物を形式の確認にだけ読んだ）。座らせた姿勢を決める。
- **`steer.ksanim`（版 2）**: 骨ごとに、名前・コマ数・各コマの回転（四元数）・位置・大きさ（40 バイト）。借り物は 55 本 × 101 コマ。ハンドルの切れ角に応じてコマが選ばれる。
- **`driver3d.ini`**: `[MODEL] NAME=`（`content/driver/` のファイル名）、`[STEER_ANIMATION] NAME=steer.ksanim`・`LOCK=`、`[SHIFT_ANIMATION]`、`[HIDE_OBJECT_n]`。この車の `STEER_LOCK` は 900°。
- 運転席まわりの位置は外装・内装の .blend と主 kn5 から測る: `STEER_HR`（ハンドルの中心と回転軸）、`DRIVER_EYE`（目の位置、kn5 座標 −0.642, 1.985, 3.407）、座席の座面と背もたれ、ペダル。
- 有料のサービスは使わない。デザイン（三面図・3D モデル）は Codex の `gpt-6.2-astra` に頼む。Blender はサンドボックスなしで動かす（サンドボックス経由だと落ちる）。

## 7. 合格の条件

この Mac で確かめる:
- 骨の名前と階層が AC 標準の運転手と一致（`DRIVER:DRIVER` から下、使う骨すべて）。
- 主なメッシュの頂点数が標準の運転手と同じくらい（1 メッシュ 6 万頂点以下、全体で数千〜1 万程度）。
- knh・ksanim を自作の読み込み器で読み戻して、骨の名前・コマ数が意図どおり。
- 座らせた姿勢で、手のひらの中心と目標の距離が 2 cm 以内（ハンドルの角度 0°、±90° で）。**（2026-11-26 改訂: 手のひらはリムの管の上、指を曲げて握る）** 目標は、リムの管の中心線から、外向きを運転手の側（上）へ倒した向きへ（管の半径 + 手のひらの厚みの半分）ずらした点。指の骨は .blend の握りのポーズで曲げ、手袋が管に 6 mm より深く入らない。体に拡大がかかっていない、肘が 15° 以上曲がっている、上体の前傾が 20° 以下、頭が `DRIVER_EYE` より下。体・脚が座席・ダッシュボード・ハンドルの柱にめり込まない（メッシュの交差を数える）。
- 元絵と並べたレンダー（正面・横）で、同じ運転士だと分かる。
- `tools/check_public.py` が通る（借り物 0、絶対パス 0）。

ゲームで確かめる:
1. 落ちない。CSP のログにこの運転手のエラーが無い。
2. 運転席の視点で、ハンドル 0°・右 90°・左 90°・いっぱいのそれぞれで手がリムを握っている。
3. 車外（斜め前・横）から、窓越しに運転士の姿が見える。

## 8. 作る人に任せること

- 三面図を作る道具の細かい使い方（Codex の画像生成）、モデルの分け方、マテリアルの数（ただし AC の ksPerPixel で表現できる範囲で、アニメ調を保つ）。
- ハンドルを大きく回したときの手の扱い（持ち替えるか、一定の角度から先はリムから手を離すか）。ただし 0°・±90° では握っていること。
- `driver3d.ini` の `LOCK` の値（`steer.ksanim` のコマとハンドルの角度の対応に合わせる）。2026-11-26 訂正: `LOCK` は片側の角度で、現在は 90（AC はコマ 0〜最後を −LOCK〜+LOCK に割り当てる）。

## 9. 確認で決めたこと（2026-11-26）

設計書を別の担当に読んでもらい、出た質問に答えた。（ユーザー）はユーザーの判断、（私）は私が決めたもの。

| 質問 | 決めたこと |
|---|---|
| 運転手のモデルのライセンス | **MIT で公開する**（ユーザー）。元絵のイラストは公開しない。骨の名前と階層は AC の運転手の仕組みに合わせるための名前で、Kunos のデータ（形・姿勢・動き）は使わない（私） |
| 運転席の視点で頭をどうするか | 顔・髪（ポニーテールとリボンを含む）・帽子を別々の名前のメッシュにして、`driver3d.ini` の `[HIDE_OBJECT_n]` で運転席の視点から隠す。車外からは見える（私） |
| 見た目の合格を誰が判定するか | 元絵と並べたレンダー（正面・横・後ろ）と、運転席から見た手のレンダーをユーザーに見せて判断してもらう（外装・内装と同じ）。astra の作り直しは 2 回まで。届かなければ選択肢（簡略化・B 案・C 案）を添えてユーザーに相談する（私） |
| 「±90°」の意味 | ハンドルそのものの回転角（前輪の切れ角ではない）。**（2026-11-26 改訂）** 手は ±90° の範囲のどの角度でもリムの上（2 cm 以内）にある。届く間は握った場所ごとリムと一緒に回り、届かなくなった手はリムの上を滑って、届くいちばん遠い場所で止まる（持ち替え）。当初の「両手がリムの同じ場所を握ったまま ±90°」は、90° 回すと遠い側の手が肩から 0.56 m 先になり、腕（0.45 m）が 11 cm 届かなかったので取りやめた。±90° より先の手の扱いは作る人に任せる（私） |
| 座席・ハンドルの形 | 今の内装（`design/interior/kanachu_interior.blend`）と主 kn5 で確定（ユーザーが外装・内装のデザインを承認済み）。足りない寸法は推定してよく、推定した値と根拠を report に書く（私） |
| 体の位置と大きさ | **（2026-11-26 改訂）** 体の大きさはモデルのまま（約 1.6 m、どの骨にも拡大をかけない）。腰は座面（`cockpit.json` の `seat_point`）に座らせ、座面の範囲で前後に動かしてよい。上体の前傾は 20° まで、肘は伸ばしきらない（15° 以上曲げる）。手はリムの真上から 60°〜100° の範囲で、届くいちばん上の位置を握る。頭は `DRIVER_EYE` より下にあればよい（運転席の視点では頭を隠すので、目を合わせる必要はない）。当初の「目を `DRIVER_EYE` に合わせる」は、視点の目が座面の 0.86 m 上（身長 1.8 m 級）で、1.6 m の体では約 1.3 倍の拡大が要り、腕も届かなかったので取りやめた。席の位置は `driver_base_pos.knh` の `RIG_Center` の行列で表し、`driver3d.ini` の `POSITION` は 0,0,0 のまま（私） |
| 変速の設定 | `[SHIFT_ANIMATION]` は残す（動きのファイルは作らない）。ゲームで落ちたら、そのときに空の動きのファイルを足す（私） |
| 試走の本数 | D7 に入る前にユーザーの承認を取る（これまでと同じ）（私） |
| 「Kanachu」の文字と名札 | 「Kanachu」は帽子の徽章と胸の刺繍に入れる（描き直した字）。名札は白い板だけで、名前は入れない（私） |
