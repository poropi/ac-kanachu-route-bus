## ユーザーに決めてもらったこと（当初の問い）

1. **§8-3**：AI が 91 秒で瞬間移動する件をどう扱うか。
   - (a) 瞬間移動したあとにもう一度走り出させて、合計 3 分にする。
   - (b) 走れた 80 秒で良しとする。
   - (c) 別のコースで走る。
2. **§8-5 の後半**：どこでどう測るか。
   - (a) nevadadrift の広場（スタートの後ろ側）へ向かってから回る。
   - (b) 別の広いコースを探す。
   - (c) 測らずに、タイヤの横の摩擦を 0.85 から下げておく。
3. **運転手の人形**：設計書 §5 は「手が合わなければ人形なし」だが、人形の 3 ファイルを抜くと CSP が落ちる。
   - (1) このまま出す（§9 に記載済み）。
   - (2) 3 ファイルは残して人形を見えなくする（方法はゲームで要確認）。
   - (3) LOCK を 900° にして手の位置を詰める。
4. **追従視点**：ユーザー判断で F6 の確認を 2 本走らせた。分かったのは次のとおり。
   - AC は F6 を 6 台までしか読まない。最初に足した 7・8 台目は使われていなかった。
   - F6 の 3・4 番を後ろ上方の 2 台に入れ替えた。追加で承認をもらった 1 本（`circle_drift_20261126_121943`）で、車体全体と前方の道が見えることを確認した。F6 は MOD の中のファイルなので、配布するだけで効く。
   - AC の F1 追従カメラ（近・遠）は、後面が画面いっぱいになることを画像で確認した。

決まったこと（2026-11-26）：§8-3 は 80 秒で可。§8-5 の後半は摩擦を 0.72 に下げて代用測定。人形はこのまま出す。F6 は確認走行 2 本。
