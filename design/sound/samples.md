# 神奈中バス・エンジン音素材

[engine/](engine/) の20本が FMOD への取り込み用。すべて 48 kHz、16 bit PCM、モノラル、3.000秒。ファイル全長をループ範囲にする。車外は `engine_ext`、車内は `engine_int` の load / coast に分け、各ファイルを表の自然回転数で等速に置く。2,600 rpm では 2,400 rpm 素材を約1.083倍で鳴らす。[loopcheck/](loopcheck/) は同じ PCM を3周つないだ9秒の試聴用。[effects/](effects/) の付属音は1回再生する。

## 回転数を決めた根拠

原録音にタコメーターの記録はない。4ストローク直列4気筒では1回転につき2回燃焼するため、燃焼基本周波数を f Hz とすると自然回転数は 30 × f rpm になる。ここで示す値は、録音の周期を4HK1相当の燃焼周期として扱ったときの推定値。提供素材の録音車種は未特定。

原録音の時刻は各 MP3 を先頭から復号した秒数。波形に Hann 窓を掛けて FFT で基本波と2・3次のピークを測った。下表のループの燃焼周波数は、低域の繰り返しに合わせて選んだ周期数を、重ね合わせ後の長さで割った値。ピッチ倍率は目標周波数をこの値で割っている。

| アイドル | 23478 | 2.1000–5.4332 | 30.03 / 60.06 / 90.00 | 30.001 |
| 回転上昇後 | 23478 | 27.6000–29.2684 | 49.26 / 98.69 / 147.77 | 49.142 |

## エンジンループ

自然回転数は**完成 WAV の再測定値**。基本波・2次・3次のピークのうち、周辺のスペクトル中央値を8 dB以上上回るものを採用し、各周波数を次数で割った値の中央値から計算した。「—」はその次数のピークがこの条件に届かなかった箇所を示す。

素材・倍率の並びは、アイドル／回転上昇後／車内振動（int のみ）の順。回転上昇後の混合率が 0.45 なら、等 RMS にしたアイドルを 0.55、回転上昇後を 0.45 の振幅で混ぜる。coast は回転上昇後の成分と高域を減らして惰行を表現した。原録音にアクセル開度の記録はない。

EQ 欄はハイパス Hz／ローパス Hz／720 Hz を中心とする高域シェルフ dB。車内は約122 Hzの共鳴を足し、ID 22321 を24–145 Hzに絞った床振動を振幅比0.22で重ねた。アクセル開度を変えたときに燃焼周期がずれないよう、同回転の4本は共通の位相で切っている。RMS は完成ファイル全体をフルスケール ±1 基準で測った値。

## ループの継ぎ目

録音区間の両端を4燃焼周期分だけ余弦カーブで重ね、移調後の3秒ループでも5周期分を重ねた。音色のばらつきを抑えるため、各視点・負荷で、同じ燃焼次数を中心とする広い帯域のエネルギーを5回転点間で比較した。対数回転数に対する傾きを最大±5 dB/octに制限した傾向線へ寄せる循環 EQ（各帯域で最大±7 dB）を掛け、同回転の4本を一緒に回転させて、隣接サンプルの変化が小さい位置に境界を置いた。

試聴 WAV を読み戻し、3秒と6秒の両方で測定した。2か所とも同じ数値。段差は境界直後と直前の1サンプルの差の絶対値、局所最大は境界前後各20 ms（各960サンプル）の中での隣接サンプル差の最大値。単位は16 bit PCMの1目盛り（1 LSB = 1/32768 FS）。前後の RMS は同じ20 ms窓の音量。低回転では20 msが燃焼1周期より短いため、前後 RMS には燃焼パルス内の強弱も表れる。

## 扉とエアブレーキ

回転数・負荷は適用外。速度変更はすべて1.000倍。休止区間の雑音スペクトルを差し引き、帯域制限と短いフェードを掛けた。扉は停車中に続けて現れる2つの空気作動音を、順に開・閉として割り当てた。開閉方向は映像で確認されていない。両方とも原録音の立ち上がりを避け、ID 96993 の空気音を1,300–8,200 Hzに絞って重ねた（減衰時定数66 ms、入り4 ms、末尾20 ms、振幅は主音の RMS 比0.8）。

## 背景音の検査

完成したエンジン20本と付属音3本を Silero VAD で検査した。16 kHz・32 ms窓で発話判定値が0.5以上になった窓は0件。最大値は0.395だった。検査対象は発話で、音楽や他車音の識別は対象外。制作環境では音声を聴き取れないため、背景音の目立ち方と継ぎ目の聴感は未確認。

## 再生成

プロジェクトのルートから以下を実行する。Python 3、NumPy、SciPy、ffmpeg を使う。WAV を読み戻して3周の PCM 一致、形式、境界段差、燃焼次数を検査し、この一覧の数値も作り直す。

```sh
python3 -B design/sound/scripts/build_samples.py
```

発話検出も再実行する場合は、同梱のスクリプトで ONNX Runtime とローカルの Silero VAD モデル（h/c 入力版）を使う。

```sh
python3 -B design/sound/scripts/check_speech.py ~/.cache/torch/hub/litagin02_silero-vad_master/files/silero_vad.onnx
```

> 注記（2026-11-26）：`air_brake_release.wav`（ID 96993 を切り出して帯域を絞っただけの音）は、Pixabay の規約でいう「単体」（ほぼ元の形のまま）に当たるおそれがあり、音の bank にも使っていないため、公開用のリポジトリから外した。ほかの WAV は複数の録音・区間の合成と編集で作った別の音。
