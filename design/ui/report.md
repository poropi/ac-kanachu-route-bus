# 神奈中バスのUI用画像

[原寸と4倍のプレビュー](preview.png) は、上段が各PNGの原寸、下段が同じ画像の最近傍4倍表示。全画像の背景は透明。

## バッジとロゴ（依頼04時点）

[依頼03の新塗装PNG](../livery/paint_new2023.png) の前後面にある青い「Kanachu」と、[ロゴの作図元](../livery/scripts/artwork.py) のKを参照した。太い縦画、上下の払い、右の山形をパスで描き直し、依頼04指定の斜線を左に加えた。[128 pxのバッジ](badge.png) は右の山形を2本残し、[64 pxのロゴ](logo.png) は1本にまとめて線幅と隙間を確保した。

## 塗装見本と使用色

[旧塗装](livery_standard.png) と [2023年新塗装](livery_new2023.png) は前方を左にそろえた64 × 64 pxの側面図。旧塗装は橙帯の上下に赤縁を各1 px残した。新塗装は後輪付近の交互線を2〜3 px幅に整理し、後端の赤へつないだ。

すべて[依頼03の採色表](../livery/report.md#採色)の採用色。表に独立した黄色はないため、新塗装見本で黄色を表す線には、旧塗装の黄味の強いクリームを使った。

| 用途 | sRGB |
|---|---|
| バッジ・ロゴの青 | `#0D55D9` |
| 旧塗装のクリーム地、新塗装見本の黄ライン | `#D7CD8E` |
| 旧塗装の橙帯 | `#CA763A` |
| 橙帯の赤縁、窓上の細帯 | `#902C26` |
| 旧塗装の赤い裾 | `#B53139` |
| 新塗装の前後端の赤 | `#EC2430` |
| 新塗装の橙 | `#DE7839` |
| 新塗装のクリーム地 | `#EADAC2` |
| 共通の窓、プレビューの文字 | `#707885` |
| 共通のタイヤ、ホイール中央 | `#413123`、`#A5ACB6` |

## 再生成

プロジェクト直下で次を実行すると、[描画スクリプト](scripts/draw_icons.py) が4枚のアイコンとプレビューを出力する。Python 3、Pillow、`rsvg-convert`、プレビューの表記にArialを使用する。

```sh
python3 -B design/ui/scripts/draw_icons.py
```

## 依頼04b　塗装の K との見比べ

[実車後面の「Kanachu」](../../refs/photos/2024-05-01-13-chi85rr.jpg) と[新塗装のロゴ](../livery/paint_new2023.png) は、太い縦棒が K の左端にあり、右腕に沿って「く」の字の細線が2本並ぶ。[バッジ（128 × 128 px）](badge.png) と[ロゴ（64 × 64 px）](logo.png) は左の斜線を取り除き、塗装原画の K と同じ輪郭を縦横同じ倍率で縮尺して中央に配置した。

[プレビュー](preview.png) の上段で、64 px でも右の細線2本の間に背景が見えることを確認した。下段の4倍表示では、折り返しの前後でも2本をたどれる。スキン見本2枚は既存の PNG をそのまま使った。
