# 依頼 01c: 乗降側ミラーの前後位置を、正面と左斜め前の両方の写真に合わせる

依頼 01b の照合と直しをありがとうございます。重ね合わせはよく合っています。残った乗降側（車の左）ミラーを直してください。決まり（書き込みは `design/exterior/` の下だけ、git 操作なし、座標・名前・UV・寸法の決まり）は前回と同じです。前回の内容は `design/exterior/report.md` と `scripts/` を読んで把握してください。Blender は `/opt/homebrew/bin/blender`。

## 直すこと

- **全長 10,430 mm はミラーを含まない値として扱う**（依頼 01 で明記していなかったのは私の不足です）。ミラーを含めた長さは制約にしない。全長はミラー・ワイパー・ナンバーを除いた車体で ±20 mm。
- 正面の写真（な39）ではミラーの左右と高さの位置が合い、左斜め前の写真（ふ43）では約 50 px 右にずれる。正面の写真には前後方向の位置が写らないので、**ずれているのは前後方向の張り出し（Y）とアームの形**と考えられる。左斜め前の写真で、縦長の鏡・丸い鏡・アームの付け根の 3 点の位置が合うように、アームの前への張り出しと曲がりを直す。正面の写真での一致は保つ。
- 運転席側（右）のミラーも、同じ見方で前後位置を確かめ、ずれていれば直す。
