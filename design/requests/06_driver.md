# 依頼 06: 神奈中バスの運転士の三面図

あなたはキャラクターデザイナーです。Assetto Corsa の神奈中バス MOD で、運転席に座る運転士（オリジナルのキャラ）の 3D モデルを作る前に、モデラーが見て作れる**三面図（正面・横・後ろ）**を描いてください。

## 作業場所と書き込みの範囲

- 作業フォルダ: このリポジトリの最上位（`ac_kanachu_bus/`）
- **書き込んでよいのは `design/driver/turnaround/` の下だけ。** git の操作はしない。Blender は使わない。
- 元絵: `refs/driver/illustration.png`（ユーザーのイラスト。**見るだけ**。切り貼り・トレースしない。三面図は新しく描く）

## 描く人物（元絵から。ユーザー確定）

| 部位 | 内容 |
|---|---|
| 髪・目 | 茶色のサイドポニーテール（本人の左、元絵で向かって右）、薄紫のリボン、紫の目 |
| 帽子 | 濃紺の制帽、正面に楕円の「Kanachu」の徽章 |
| 上着 | 濃紺の背広型。襟・袖口・ポケットのふたに青い縁取り、胸に「Kanachu」の刺繍と白い名札（名前は書かない、無地）、銀のボタン 3 つ |
| シャツ・ネクタイ | 白いシャツ、紺と青の斜めストライプのネクタイ |
| 手・下 | 白い手袋、濃紺のズボン、黒いローファー |

- **表情は目を開けた笑顔**（元絵のウインクと大きく開けた口は使わない）。
- 「Kanachu」の文字は帽子の徽章と胸の刺繍だけ。ほかに文字・ロゴを入れない。
- 体型は大人の女性、身長 1.60 m 前後。

## 描き方の決まり

- 3 枚とも**同じ人物・同じ縮尺・同じ足元の高さ・同じ頭頂の高さ**。立ち姿で、**腕は体から少し離して下ろす（A ポーズ）**、手は軽く開く、足は少し開いて正面を向く。
- 背景は無地の白。影や小物は描かない。アニメ調の塗り（元絵に近い色）。
- 正面・横（本人の左側面、ポニーテールの側）・後ろ。

画像の生成・編集の道具（ChatGPT の画像生成）を使う。元絵は `-i` で渡されている。
