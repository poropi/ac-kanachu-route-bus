# 依頼 04: Assetto Corsa の UI 用の絵（バッジ・ロゴ・スキンの見本）

あなたはグラフィックデザイナーです。神奈中バスの Assetto Corsa 車 MOD の、選択画面などに出る小さな絵を作ってください。

## 作業場所と書き込みの範囲

- 作業フォルダ: このリポジトリの最上位（`ac_kanachu_bus/`）
- **書き込んでよいのは `design/ui/` の下だけ。** git 操作はしない。処理はスクリプトとして `design/ui/scripts/` に残す。

## 作る物（すべて PNG、背景は透明）

| ファイル | 大きさ | 中身 | AC での使われ方 |
|---|---|---|---|
| `badge.png` | 128×128 | 「Kanachu」ブランドのバッジ。青い「Kanachu」ロゴの K の形（太い K の左に青い斜めの線）を中心にした、正方形に収まる絵 | 車の選択画面のブランドの印 |
| `logo.png` | 64×64 | badge と同じ意匠を 64 px で読めるように簡略化 | 車フォルダの印 |
| `livery_standard.png` | 64×64 | 旧塗装の配色の見本（クリーム地に赤・橙の帯、裾の赤）を、車の側面を模した横長の帯の図案で | スキン選択の小さな見本 |
| `livery_new2023.png` | 64×64 | 新塗装の配色の見本（赤・クリーム、後ろ寄りの赤・橙・黄の縦ライン） | 同上 |

## 決まり

- ロゴは描き直す。写真や既存の画像を貼らない。ロゴの形は `design/livery/paint_new2023.png` と `design/livery/report.md`（依頼 03 で描き直した Kanachu ロゴ）に合わせる。
- 色は `design/livery/report.md` の色の表の値を使う。
- 64 px の絵は、実寸で見て読めること（細い線は太らせる）。

## 届ける物（`design/ui/` の下）

- 上の 4 枚
- `preview.png`: 4 枚を実寸と 4 倍の両方で並べた確認用の 1 枚
- `report.md`: 使った色と、元にしたロゴのファイル
